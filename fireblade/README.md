Как получить готовый .jar без установки чего-либо (GitHub Actions)
1. Создай на github.com новый репозиторий (можно приватный).
2. Загрузи в него ВСЁ содержимое этой папки, включая скрытую папку .github
   (проще всего: Add file -> Upload files, перетащить все файлы и папки).
3. Открой вкладку Actions -> "Build mod" -> дождись зелёной галочки (2-5 минут).
   Если не запустилось само: Run workflow.
4. Открой завершённый запуск, внизу в разделе Artifacts скачай fireblade-jar.
5. Распакуй скачанный zip -> fireblade-1.0.0.jar положи в папку mods (Minecraft 1.20.1 + Forge 47.x).

Локальная сборка: JDK 17 и Gradle 8.1.1, затем команда  gradle build
Результат: build/libs/fireblade-1.0.0.jar
